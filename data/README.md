## Where the data comes from

San Diego International Airport (SAN) hourly observations, 2006–2025,
via the Iowa State IEM ASOS archive. The four source CSVs were downloaded
as 5-year chunks. If you do not have them, download the SAN station data
from IEM ASOS for 2006–2025 and split by the same year ranges, or ask the
project owner for the source files.

## How the model-ready file is built

```bash
# From the data/ dir (or any dir containing the 4 source CSVs):
Rscript ../src/data_prep/pipeline_20year_san.R
# Writes SAN_20year_processed_analytics_v2.csv + SAN_20year_model_ready.csv
```

The pipeline: merge → hourly aggregation → full hourly grid + imputation
→ feature engineering (lags, 24-h rolling stats, wind sin/cos, heat index,
wind chill) → PCA fit on training years only (≤2021) → model-ready CSV
with the `year` column kept for splitting.

## Splits (used by every later step)

- Train: `year <= 2021`
- Validation: `2022–2023`
- Test: `year >= 2024`

## Targets (6)

`temperature_c`, `relative_humidity_pct`, `wind_speed_ms`, `pressure_hpa`,
`visibility_km`, `heat_index_c`. All other columns in the model-ready CSV
are features (except `year`).
